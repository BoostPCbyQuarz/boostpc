git push

## Mettre à jour le compteur de PC optimisés

Chercher (Ctrl+F) : <strong>16</strong>

Present dans le footer de CES 9 fichiers :
- index.html
- pages/services.html
- pages/resultats.html
- pages/avis.html
- pages/communaute.html
- pages/apropos.html
- pages/faq.html
- pages/partenariat.html
- pages/contact.html
- pages/mentions-legales.html

Remplacer le nombre 16 par le nouveau chiffre dans chacun, puis :
git add .
git commit -m "Mise a jour compteur PC optimises"
git push
